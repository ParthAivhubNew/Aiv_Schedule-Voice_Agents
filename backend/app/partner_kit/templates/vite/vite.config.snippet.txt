ADD THIS TO YOUR vite.config.ts (or vite.config.js)
Open the file, find defineConfig({ ... }) and add the "server" line inside it. If you already have a "server" setting,
add the "proxy" part to it and keep your other settings (port, host and so on).

    export default defineConfig({
      plugins: [react()],
      server: { proxy: { "/outreach-start": "http://127.0.0.1:3000" } },
    });

Then stop and start your app (npm run dev). A change to the proxy only takes effect after a restart.
